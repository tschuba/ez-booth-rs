# EZ Booth Downloaded Build

## Quick Start

1. Extract the downloaded artifact archive.
2. Open `index.html` in Chrome or Safari.
3. The app runs locally and stores data in the browser on that device.

## Notes

- Keep all extracted files together in the same folder.
- For best results, use a current Chrome or Safari version.
- Browser storage stays on the device and browser profile where you open the app.

## Optional Local Server

If a browser or environment blocks direct file access, serve the folder locally instead:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.
